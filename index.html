Documentation — CRA Advisory for Jira

Last updated: 2026-11-19

CRA Advisory for Jira runs inside Jira. It tracks the Article 14(8) clocks, prepares the reporting fields, and drafts the customer advisory.

Use the App

  1. Open an issue and start the CRA clock. Choose the track, the date, and the time you became aware.
  2. Open the war room. Fill the report pack for the CSIRT, then save it. The 72-hour and final notices are separate from the 24-hour notice. Save copies the shared fields forward.
  3. Open the customer advisory. Keep the affected versions and the mitigation. Leave exploit detail out. Save it.
  4. Copy CSAF for a file oriented to CSAF 2.0. Download the dossier PDF for the CSIRT.
  5. A wrong awareness time is corrected on the same issue. The first time stays in the log. Deadlines use the latest time.

Project settings holds the product registry and the escalation roster. Add a Jira user there when that person should see a threshold mark inside the App.
